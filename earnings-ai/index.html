The Signal

Sentiment climbed from +0.20 in Feb 2026 to +0.78 today, across 4 filings. Apple reported Q3 2026 net sales of $109.4 billion, up 16% year-over-year, driven by strong product and services growth.

The Problem

Every quarter, 10-Q filings arrive as 40+ pages of boilerplate that hide two or three sentences that actually matter.

Retail investors either skim, miss the shift in tone, or defer to headlines. Analysts pay Bloomberg terminals thousands a month for tools that pre-digest this. I wanted to see how close a weekend project could get.

The core question: could a language model surface the same signal a first-year analyst would pull out of a filing — beats, misses, guidance changes, new risk factors, tonal shifts — cheaply enough that a single ticker costs fractions of a cent, and quickly enough that it feels like a Google search rather than a batch job?

How it Works

Ticker in, filing brief out — with every step cached so re-runs are free.

// The pipeline behind one ticker submission: 1. ticker → SEC EDGAR // ticker → CIK → 4 recent filings 2. filings → HTML stripper // raw 10-Q text, cached by (cik, accession) 3. latest quarter → AlphaVantage // earnings call transcript, if available 4. filing + transcript → Groq LLM // gpt-oss-120b, cached by content_hash + prompt_version 5. older 3 filings → Groq LLM // quick sentiment scores → history sparkline 6. result → Turso (libsql) // runs table → permalink → shareable URL 7. filing date → yfinance // ±30-day price series, market reaction

Everything server-side. The frontend is a single HTML page that streams progress over Server-Sent Events, then renders the brief when the pipeline finishes.

Every step sits behind a Turso-backed cache keyed by content_hash + prompt_version, so a second run of the same ticker is instant and costs zero LLM tokens. Bump the prompt version → old rows age out naturally without a migration.

The Redesign

The first version was a dashboard. That was the problem.

Version one landed the pipeline but delivered its output as a grid of metric cards, gauges, and Chart.js line charts. Functional, forgettable — the kind of thing every fintech tutorial ships. Nothing to forward to a friend.

Version two threw the dashboard out. In its place: a single editorial page — a "Filing Brief" — that reads like a Bloomberg opinion column with data woven through the prose. Section 01 is the signal, told as a paragraph with a sparkline embedded mid-sentence. Section 02 is the pull quote from management, magazine-style. Section 03 is analyst pushback from the earnings call, laid out as a "vs." panel. Section 04 is the market's answer, drawn as a Financial Times hairline chart with a small pill marker at the filing date. Everything else — themes, risks, insider trades, congressional trades — collapses under a single progressive-disclosure toggle labeled The Evidence.

The typographic system does the heavy lifting. Manrope 800 for the display voice, Instrument Serif for editorial labels and pull-figures, Inter for body prose. Bicentra Biotech's brand identity was the reference — precise cobalt on warm cream, generous vertical rhythm, restraint over decoration.

Feature Focus · Diff Mode

Filings are only interesting relative to the last one. So the app compares any two runs and tells you what actually changed.

  1. Sentiment shift. A signed delta between two runs' sentiment scores, plus the label flip if it crossed a threshold.
  2. Themes added and dropped. Set operations on the LLM's key-themes list — a new "AI acceleration" theme appearing three quarters in a row is a real signal.
  3. Beat/miss flip. When management stops missing estimates and starts beating them, the diff surfaces it explicitly instead of burying it in the summary.
  4. New analyst concerns. Only shows up when a transcript was available — pulls the questions analysts asked that last quarter's call didn't cover.

Feature Focus · Earnings Call Context

The 10-Q tells you the numbers. The call tells you the confidence.

When AlphaVantage has a transcript for the quarter, the analyzer feeds an excerpt of it into the LLM prompt alongside the filing itself. The model compares the polished written filing against how executives actually talked about it — and against what analysts pushed back on.

The brief gains an editorial pull quote from the CEO or CFO, a tone analysis grounded in the transcript, and a "What Analysts Pushed Back On" section rendered as a two-panel vs. layout. If no transcript is available, the section quietly disappears — the app degrades to filing-only mode with no error state and renumbers the remaining sections automatically.

Decisions worth calling out

Turso over Postgres

The app is read-heavy and SQLite-shaped. Turso keeps the SQLite dialect but runs the authoritative copy in the cloud with an embedded replica on the app machine — reads are local (nanoseconds), writes sync asynchronously. Free tier gives 9 GB storage and 1B reads/month, enough to never think about it. Postgres would have been a heavier dependency for zero gain.

Prompt versioning as invalidation

Instead of a TTL, the LLM cache is keyed by (content_hash, prompt_version, model). Any prompt change → bump the version constant → old rows are effectively invalid, new runs re-analyze. Old rows stay for provenance until pruned.

Server-Sent Events over polling

The analysis pipeline takes 8–25 seconds — long enough that a progress indicator matters. SSE gives me a single unidirectional stream of progress messages ending in the final result, and works with plain gunicorn --worker-class gthread. WebSockets would have been overkill.

API keys never leave the server

Groq and AlphaVantage keys live in Render secrets, injected as env vars. The frontend has no notion of them. A five-ticker demo whitelist caps blast radius from anyone hitting the URL — everything else is a friendly 403.

Editorial over dashboard

Every fintech tool defaults to a card grid. This one defaults to a single editorial page with progressive disclosure. The signal isn't a metric card labeled "Sentiment: +0.78" — it's a sentence: "Sentiment climbed from +0.20 in Feb 2026 to +0.78 today." Sparkline lives inside the sentence.

$0/month at 20 users

Render's free web tier + Turso's free storage tier. The container sleeps after 15 minutes of no traffic and wakes in ~1 minute on the next visit — disclosed to visitors directly via an "About this demo" pill so nothing feels broken. If cold starts ever matter, ~$0.20/month on Fly.io removes them.
